## 🎬 Overview

**CineStream Engine** is an end-to-end data processing pipeline and recommendation system built on top of the MovieLens dataset (+100,000 ratings across 9,700+ titles). 

The project demonstrates production-ready data engineering and Machine Learning workflows, covering:
* **Data Quality & ETL:** Automated handling of missing values, orphan records removal, and data normalization using Pandas and NumPy[cite: 1].
* **Exploratory Data Analysis (EDA):** Statistical profiling of user engagement, rating distributions, and genre relationships with Matplotlib[cite: 1].
* **Recommendation Algorithms:** Implementation of Collaborative Filtering (Cosine Similarity) and Content-Based Filtering for personalized film predictions[cite: 1].
